FAQ

Common questions


Is AppliedIn completely free?
Yes. Free forever. No subscription, no premium plan, no hidden charges, no ads. Download from GitHub and use it at zero cost.
Which job portals are supported?
LinkedIn, Naukri, Internshala, Indeed, Glassdoor, Unstop — all automatic. Plus any company career website like TCS, Infosys, Wipro, Deloitte, Accenture, and more.
Is my data safe? Who can see my applications?
Nobody. All data is stored only on your own device, in your browser’s local database. There is no server and no account, so not even the developer can see your applications. Use the Back up button now and then — uninstalling the extension deletes local data.
How do I install it without the Chrome Web Store?
Download the ZIP from GitHub → Open chrome://extensions → Turn on Developer Mode → Click Load Unpacked → Select the extension folder. Done in under 2 minutes.
What if I apply on a company's own website — like TCS or Infosys?
AppliedIn remembers the job when you click Apply. If the button opens the company website in a new tab, it shows a small “Did you apply?” prompt when you come back — tap Yes and it's saved. Hiring systems like Workday and Greenhouse are tracked automatically.
Can I export my applications to Excel?
Yes. Export to Excel (.xlsx) or CSV anytime. Choose by time period — Today, This Week, This Month, or All Time. Your data, your format, offline.
How do I update to a new version without losing my data?
Click Back up in the extension first. Then download the new ZIP, extract it into the same folder (replace the files), open chrome://extensions and press the reload icon on AppliedIn. Keep the folder in the same place — moving it creates a new extension and an empty list; if that happens, use Restore from backup.
How does AppliedIn know when a company replies?
Three ways, all optional and all on your computer: you can change a status yourself; AppliedIn reads the status text on your portal’s “my applications” pages when you visit them; and if you turn on Gmail detection, it recognises replies such as interview invitations, assessments and rejections in your open Gmail tab. Emails are never uploaded, and each automatic change is listed in the dashboard so you can undo it.
How do reminders work?
AppliedIn checks in the background every couple of hours while Chrome is open and shows one summary notification a day (after 9 am), plus an alert before an interview. The toolbar icon also shows an orange number when something needs you. If notifications don’t appear, allow Chrome in your system notification settings and press “Send a test notification” in Settings.
